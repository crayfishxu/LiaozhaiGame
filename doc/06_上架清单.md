## 一、技术侧：已达标

| 项 | 现状 | 说明 |
|---|---|---|
| 包名 | `com.liaozhai.meiren` | 一旦上传不可改 |
| 版本 | versionName `0.1.8` / versionCode `9` | 每次上传 versionCode 必须递增 |
| targetSdk | 36 | Play 新应用要求 35+，满足 |
| minSdk | 24（Android 7.0） | 覆盖 99% 在用设备 |
| ABI | arm64-v8a + armeabi-v7a | 不含 x86，模拟器需 arm 镜像 |
| 签名 | upload key（`CN=Liaozhai Meiren, O=Crayfish Studio`） | SHA-256 `4e97b4c8…0d42`；AAB 用 `jarsigner -verify` 验过 |
| 权限 | **0 个** | 完全离线，不申请 INTERNET / 存储 / 设备信息 |
| allowBackup | false | 存档不参与云备份，与「不收集数据」一致 |
| 广告 / 统计 SDK | 无 | 无三方 SDK、无网络库 |
| 加固 / 混淆 | 未启用 | Godot 导出脚本已是二进制 token（`script_export_mode=2`）；开 R8 需自备 keep 规则 |
| 启动图 | 已换成游戏图标（深鸦青底） | 不再是 Godot 默认 logo |
| 沉浸模式 | 开 | 状态栏 / 导航栏隐藏，真机已确认 |
| 返回键 | 弹窗逐层退；开场可退回开场 | 不会出现按返回直接退出 |
| 后台音频 | 切后台即停，回前台续播 | 来电 / 分屏 / 按 Home 都覆盖 |
| 多语言 | 11 语种，各 430 条 | zh_CN/en/ja/ko/es/pt_BR/ru/de/fr/it/id |
| 包体 | AAB 60 MB，通用 APK 153 MB | Play 按设备下发约 40–60 MB |

### 出包命令

```bash
tools/build_android.sh apk     # 正式签名 APK（gradle release，可分发）
tools/build_android.sh aab     # Play 上传包
tools/build_android.sh debug   # 调试包，别外发
```

口令只在 `~/.liaozhai_keystore_pass`（600），脚本与 `export_presets.cfg` 都不含明文。

### 产物校验（每次出包后跑一遍）

```bash
AAPT=$(ls ~/Library/Android/sdk/build-tools/*/aapt2 | tail -1)
$AAPT dump badging build/liaozhai-release.apk | head -6      # versionCode / label / minSdk
$AAPT dump permissions build/liaozhai-release.apk            # 应只有 package 一行
APKSIGNER=$(ls ~/Library/Android/sdk/build-tools/*/apksigner | tail -1)
$APKSIGNER verify --print-certs build/liaozhai-release.apk   # 证书 SHA-256 应为 4e97b4c8…
```

## 三、Play Console 侧（人工，不可代做）

| 栏目 | 怎么填 | 注意 |
|---|---|---|
| 应用名称 | 聊斋美人 | 30 字以内，与安装后桌面名一致 |
| 简短说明 | ≤80 字 | 建议「双面卡牌 · 三层妖境 · 每局一个确诊」 |
| 完整说明 | ≤4000 字 | 前三行最重要，会被折叠 |
| 应用图标 / 特色图片 / 截图 | 见第二节 | 尺寸不符会直接被拒 |
| 内容分级（IARC） | 含轻度恐怖、无血腥、无赌博 | 问卷里「妖怪 / 幽冥」题材按实填 |
| 数据安全 | **不收集、不共享任何数据** | 与「0 权限」一致；填错会被下架 |
| 隐私政策 | 需要一个可访问的 URL | 即使不收集数据，也建议放一页说明 |
| 广告 | 不含广告 | — |
| 应用访问权限 | 全部功能无需登录即可使用 | 我们无账号体系 |
| 目标受众 | 13 岁以上 | 含恐怖元素，不建议标 12 以下 |
| 政府 / 金融 / 健康声明 | 均不适用 | — |

### 建议的上传路径

1. 先传 **内部测试**（Internal testing）轨道，用自己的账号装一遍；
2. 再传 **封闭测试**（至少 12 名测试者连续 14 天，若账号是新注册的开发者）；
3. 最后走 **正式版**，分批发布 20% → 50% → 100%。

## 四、还没做到「正式版」的部分

按影响排序，这些不影响本次传包，但上线后会被玩家提。

| 项 | 影响 | 现状 |
|---|---|---|
| **中途存档** | 一局打到一半被杀进程就全没了 | 只存设置（音量 / 语言），不存局内进度。Roguelike 里这是差评高发点，建议下个版本做 |
| 埋点 | 不知道分享率、留存、卡关点 | 无统计 SDK。要做得先定上报通道，且会改变「零权限」现状 |
| 玩梗的时效 | 梗半年就旧 | 文案在 i18n 词表里，可整段替换；建议一季一更 |
| 难度曲线 | 三层 18 个敌人，全靠手调数值 | 没有真实留存数据前，只能凭手感 |
| 立绘覆盖 | 18 个敌人里只有 4 个有立绘 | 其余用字形占位（骨/傀/妖…），构图是刻意的，但商店截图要避开 |
| BGM 长度 | 21–33 秒循环 | 循环三四分钟能听出重复，正式版建议 60–90 秒 |

## 六、安全提醒

- **签名口令只放本地**：`~/.liaozhai_keystore_pass`（600），不要写进 README、脚本、CI 变量或聊天记录。
- **keystore 要备份两份**（离线 U 盘 + 密码管理器）。upload key 丢了可以找 Google 重置，但流程要几天。
- 仓库若转公开，先确认历史提交里没有口令、密钥、`.jks`。必要时用 `git filter-repo` 清历史，或直接轮换 upload key。
- 本仓库 `.gitignore` 已排除 `build/`、`android/build/`、`*.jks`、`*.keystore`。
