## 1. 背景与目标

### 1.1 现状

v0.1.6 已有的骨架：三关三章、**52 张双面卡（含 7 张祟）**、**17 个敌人**、**6 类地图节点**（战 / 精 / 事 / 商 / 休 / 宝 + 关底妖）、**40 件旧物**、**6 个随机事件**、**11 语种（422 条词条全对齐）**、完整的结算确诊与分享流程。内容量不再是短板，但**传播面仍然是零**：

1. ~~缺意外~~ → 地图节点已经带来随机性，「下一局可能不一样」这条已经解决；
2. ~~缺表达~~ → 事件节点的第三选项已经给了「只有我会这么选」的位置；
3. **缺谈资** —— 分享卡做出来了，但还没有形成「打完想晒」的习惯，这是本期唯一没闭环的目标。

所以本文档的重心在 v1.1 之后发生转移：**不再论证「要不要做地图和旧物」，只看梗本身还差哪几条。**


### 1.2 一句话立场

> **能被玩家说出口的梗，做成机制；只能被玩家看出来的梗，写进文案；两者都不沾的，不做。**

举例说明三种处理：

| 梗 | 处理 | 理由 |
|---|---|---|
| 已读乱回 | **做成卡**，显相「已读」/ 本相「乱回」 | 它本身是一个「行为」，能直接翻译成规则，且和双面卡机制天然咬合 |
| 正式确诊为 XX | **做成结算标签**，读你的打法数据 | 它是一种「被评价」的欲望，做成系统比写成玩笑有用 |
| 野生狗奶 | **只写进旧物 flavor text** | 它的乐趣就在那句无厘头，做成机制反而不好笑 |

### 1.3 成功指标（上线后 30 天）

| 指标 | 现状 | 目标 | 说明 |
|---|---|---|---|
| 结算页分享率 | 0%（分享卡已上线，尚未埋点） | ≥ 8% | 「确诊」标签 + 分享按钮 |
| 次日留存 | 待埋点 | +5pp | 事件节点带来「下一局可能不一样」的预期 |
| 单局重开率 | 待埋点 | +10pp | 见 P1-1 委屈机制，降低挫败感 |
| 事件节点第三选项点击率 | — | 25%–40% | 这是「梗被接住」的直接证据，低于 15% 说明梗选错了 |

## 2. 梗的选用原则

这一节比后面的需求更重要。选错梗的代价不是「不好笑」，是让游戏显得廉价。

### 2.1 三条硬规则

**规则一：只用「行为 / 情绪类」，不用「事件 / IP 类」。**

行为类梗（已读乱回、正式确诊、电子布洛芬）描述的是人的普遍状态，五年后依然成立；事件类梗（雪山救狐狸的台词、牢九门）依附于某个具体作品或某次传播，半年后就是化石。

**规则二：零 IP 风险。**

| 淘汰 | 原因 |
|---|---|
| 袋鼠 MJ / 外卖骑手梗 | 形象版权属美团，商用即侵权 |
| 牢九门 | 源自《王者荣耀》，腾讯 IP |
| 光之国大乱斗 | 奥特曼 IP |
| 大智斗时代 / 五代石国 | 《熊出没》IP |
| 奶娃（原形象） | 来源作者已删号，权属不清 |

**规则三：叙述者可以玩梗，角色不可以。**

游戏里有三种声音：旁白、角色、系统提示。**只有旁白和系统提示能玩梗**，聂小倩和姥姥的台词必须保持原样。玩家能接受一个说风凉话的旁白，不能接受一个说网络用语的清代女鬼。

## 4. 需求清单

> 优先级：P0 本期必做 ｜ P1 本期争取 ｜ P2 下期

### P0-1 确诊（正式确诊为 XX）· ✅ 已上线

**梗来源**：2026 年最出圈的自嘲梗，用医院诊断书的句式调侃自己的生活状态。

**玩法转译**：局末按玩家的真实打法数据，给一个「病名」+ 一句短评。不是随机抽，是读数据算出来的——玩家能感觉到「它真的在看我」。

**判定数据**（本局累计，不跨局）

| 变量 | 含义 |
|---|---|
| `R` | 本局回合数 |
| `P` | 打出卡牌总数 |
| `S` | 空过回合数（结束回合时手牌 ≥ 3） |
| `L` | 自损魂火总量 |
| `B` | 获得障总量 |
| `D` | 弃牌总数 |

**八个档案**（打分取最高，同分按表中顺序）

| 病名 | 条件 | 短评 |
|---|---|---|
| 确诊为「摆烂人」 | `S ≥ R × 0.3` | 你什么都没做，雾自己散了。 |
| 确诊为「猛冲怪」 | `P / R ≥ 3.5` 且 `L ≥ 10` | 你不是在打牌，你在拿命换牌。 |
| 确诊为「龟壳精」 | `B ≥ 100` | 你把自己包好了，连风都进不来。 |
| 确诊为「手滑居士」 | `D ≥ 15` | 有些牌，是它自己想走的。 |
| 确诊为「内耗选手」 | `R ≥ 25` | 你在里面待了很久。她也陪你待了很久。 |
| 确诊为「嘴硬」 | 通关时魂火 ≤ 10 | 只剩一口气，还说不疼。 |
| 确诊为「查无此人」 | `R ≤ 2` 且失败 | 兰若寺没记住你的名字。 |
| 确诊为「情绪稳定」 | 全程单次受伤 ≤ 8 且通关 | 你从头到尾没有慌过。 |

**输出**：结算面板底部一行小字 `—— 本局确诊为「猛冲怪」`，下方两个按钮「复制文案」「保存图片」，文本格式：

```
【聊斋美人】本局确诊为「猛冲怪」
23 回合 / 出牌 86 张 / 自损 14 / 怨气峰值 9
你路过兰若寺，顺手拆了半座庙。
```

**实现说明（v1.1）**：归档为 `Run.evaluate_diagnosis()`，8 个标签的判定全部读 `Run.stats`（rounds / played / skipped / self_damage / max_hit / block_total / grudge_peak / discards）；分享卡由 720×960 的 SubViewport 渲染成图，可直接存相册，也可只复制文案。

**设计约束（已拍定）：不给任何属性加成。** 一旦有加成，玩家会为了标签扭曲打法，它就变成了第二个成就系统，不再是「被看见」。这一条从「建议」升级为**硬约束**，后续任何版本都不得为确诊标签加数值。

**验收**：八个档案在正常对局中均可触达；不出现两份档案分数完全相同（同分走表内顺序）；失败局也要出标签。**已通过**：8 个标签在构造对局中均可命中，失败局正常出标签。


**成本**：1.5 人日（纯结算层，无战斗改动）。

### P0-2 雪山问话（雪山救狐狸）· ✅ 已上线

**梗来源**：AI 短片《雪山救狐狸》的荒诞对话结构——「你可曾在雪山救过一只狐狸？」「我不是狐狸，我是那只酱板鸭。」

**玩法转译**：做成一个**问话事件**。关键不在台词，在**第三个选项**。前两个选项是正常的游戏选择，第三个是「不按剧本来」——玩家一旦发现这里可以乱答，就会去试。

**触发**：地图上的 `event` 节点，由 `MapGen` 按权重插入（事件大类权重 20/100，内部 6 个事件等概率）。

**界面**：雾中一个背对你的人影，头顶一行字：

> 「你可曾在雪山救过一只狐狸？」

**三个选项**

| 选项 | 结果 | 设计意图 |
|---|---|---|
| ① 救过 | 魂火上限 +5（直接生效） | 正常玩家的安全答案 |
| ② 没有 | 战一场（游魂 ×1，血量 ×1.3） | 给想打架的人 |
| ③ 我是那只酱板鸭 | 获得祟牌「酱板鸭」 | **奖励乱答的人** |

> 与初版设计的偏差：选项①原本打算给一件叫「狐裘残片」的旧物，实现时改为**直接 +5 魂火上限**。理由是旧物有 40 件、稀有度分档，专门塞一件只在这一个事件出现的旧物，会让掉落池多一个孤儿条目；而 +5 上限本身就是这个事件要给的收益，道具是多余的一层包装。

**「酱板鸭」**（祟 · 0 费 · 不可打出 · 不可移除）

> 占一个手牌位。每回合开始时回复 1 点魂火。
> flavor：*它本来是只鸭子。后来它被问烦了。*

这是全游戏唯一一张「负面牌但有正面收益」的祟——用 1 个手牌位换每回合 1 点回复。玩家会边骂边留着它。

**验收**：三个选项都能选到；选③后牌组里确实多一张「酱板鸭」；「酱板鸭」不可打出、不可被弃牌效果以外的方式移除；每回合开始确实 +1 魂火。**已通过**。

**决策：这类祟牌进图鉴。** 「酱板鸭」以及全部 7 张祟（心魔 / 妄念 / 邪祟 / 业障 / 怨念缠身 / 酱板鸭 等）都进图鉴，图鉴页脚写明「共 52 张，含全部祟」。理由：祟是构筑里真实存在的一类牌，玩家会想知道「到底有多少种祟在等我」——把祟藏起来，收集度就是假的；而且祟的文案本身就是氛围的一部分，值得被读到。

**成本**：3 人日（含节点 UI、判定、新祟牌）。

### P0-3 已读 / 乱回 · ⬜ 未开始

**梗来源**：社交行为梗——看到消息、不认真回、答非所问，既礼貌又终结话题。

**玩法转译**：这是全场最巧的一条——**双面卡机制本身就是「已读」和「乱回」**。显相是「我看到了」，翻面是「我乱答」，一张牌两个面，正好对上。

**新机制：意图篡改（rewrite）**
与既有的「缠绕」区分：

| | 缠绕 | 篡改 |
|---|---|---|
| 效果 | 目标完全跳过回合 | 把目标的意图**换成另一个**可预测的动作 |
| 心智 | 我让它停下 | 我替它决定做什么 |
| 收益 | 消除威胁 | 把「噬魂 16」变成「乱打 4」，同时保留信息 |

**卡牌**

| 字段 | 值 |
|---|---|
| 编号 | 新号（卡池已扩到 52 张，按现有 `CardDB` 的 key 命名规则取 `yidu`，不再用 Q 系列序号） |
| 类型 | 念 |
| 费用 | 1 |
| 目标 | 需要 |
| 显相「已读」 | 目标本回合意图改为「防御 6」 |
| 本相「乱回」 | 目标本回合意图改为「攻击 4，随机目标」，并抽 1 张牌 |

**为什么是这两个数值**：防御 6 相当于帮敌人做了一次最低效的选择；攻击 4 随机目标在双敌人关卡里可能打到自己人——玩家会为了看这一下而反复用。

**多语言**：这条是**全球通用**的罕见案例。日语的「既読スルー」、韩语的「읽씹」、英语的「left on read」都是完全对等的日常说法，直译即可，不需要改写。

**验收**：对已缠绕的敌人使用时，篡改覆盖缠绕状态（以最后生效者为准）；对死人无效；抽牌部分走正常抽牌堆逻辑。

**为什么没随本轮上线**：这一条要动的是**意图系统本身**（新增一种「被改写」的意图状态、改完还要正确显示在敌人头顶），而本轮的工作量全花在地图 / 旧物 / 52 张卡 / 分享卡上了。硬塞进来的话，会变成「卡做出来了但意图显示不对」的半成品——不如留到下个版本单独做，跟「验牌」一起做更划算，两者都要读意图序列。

**成本**：2 人日。

### P1-1 委屈（哭哭马）· ✅ 已上线

**梗来源**：2026 马年的委屈脸小马玩偶，代表「轻度崩溃、日常 emo、但不矫情」。

**玩法转译**：不做表情包，做一条**负反馈补偿机制**。当前版本玩家一旦被压制就进入死亡螺旋，没有任何翻盘钩子——这才是真正影响乐趣的地方。

**新状态：委屈**（玩家侧）

| 项 | 规则 |
|---|---|
| 获得 | 单回合内累计受到 ≥ 10 点伤害时 +1 层 |
| 上限 | 3 层 |
| 效果 1 | 回合结束时，每层获得 3 点障 |
| 效果 2 | 受到伤害时，消耗 1 层，减免 3 点 |

**视觉**：玩家血条右侧出现一个小马剪影，三档表情随层数变化（低头 / 眼角泛红 / 掉一滴泪）。**不使用任何现有玩偶形象**，自绘抽象剪影。

**为什么这是「提高乐趣」而不是玩梗**：它把「挨打」从纯损失变成了资源积累，玩家在劣势时会想「再撑一回合，我马上有障了」，而不是「这局没了」。这是纯粹的数值心理学，和梗无关——梗只负责让这个状态有个名字。

**验收**：单回合受伤 10 点触发；三层封顶；减免在障之后结算；回合结束的障不参与「本回合」判定，不留到下一回合。

**实现说明（v1.1）**：`Battle.gd` 里的 `grievance` 字段，注释直接写死「仅玩家」。触发在 `_damage_player`：单回合累计 ≥10 点才 +1 层，且**每回合只发一次**（`_grievance_awarded` 闸门），避免多段攻击一次打满三层。减免在扣血前结算（-3），回合结束按 `层数 × 3` 给障。

**决策：委屈只对玩家生效。** 敌人不加委屈。理由是这条机制的目的写得很清楚——「把挨打从纯损失变成资源积累」，它服务的是**玩家在劣势局的心理**。给敌人也加，等于双方都在挨打后变强，劣势方的翻盘窗口反而被抹平了，机制立刻失效。另外，敌人数量多，逐个数委屈层数会让界面变得难读。

**成本**：2.5 人日（含数值调平）。

### P1-2 电子布洛芬 · ✅ 已上线

**梗来源**：能治愈坏情绪的网络事物——刷视频、看萌宠、听歌。

**玩法转译**：做成**休息节点的第三个选项**。正常休息节点是「回血 / 删牌」，第三个选项是「什么都不干，就歇会儿」——收益低但带一个下局战斗的小 Buff。

| 选项 | 效果 |
|---|---|
| ① 打坐 | 回复 15 魂火 |
| ② 焚稿 | 移除 1 张牌 |
| ③ 檐下听雨 | 回复 8 魂火 + 下一场战斗首次出牌不消耗心力 |

**设计意图**：给「我这套牌已经成型了，不需要再改」的玩家一个不亏太多的选项。目前这类玩家在休息节点只能硬选一个不需要的收益。

**flavor**：*雨下了很久。你没有想任何事，这在兰若寺是奢侈的。*

**实现说明（v1.1）**：休息节点三选一，第三项就是「檐下听雨 · 回复 8，下场首牌免费」。免费首牌由 `Run.free_play_next` 记一局，跨战斗保留到下一场第一个出牌为止，所以玩家可以先在休息点买下、再决定怎么用。

**为什么这一条便宜且值**：它没有新状态、没有新数值，只是把「休息」从「二选一」变成「三选一」，却正好补上了一类玩家的空缺——牌已经成型、不需要删牌、血也够，原本只能硬点一个不需要的收益。

**成本**：1.5 人日。

### P1-3 浊胎（增殖祟）· ⬜ 未开始

**梗来源**：AI 生成的一团黄色不明生物，创作者自己都删号跑了，留下「亿万二创，找不到原作者」的荒诞局面。

**玩法转译**：**这是「化梗」而不是「贴梗」的示范**。直接叫「奶娃」会破坏世界观，也会显得在蹭；但它描述的东西——一个来路不明、自我复制、越堆越多的怪东西——恰好就是「祟」的定义。

所以：**梗丢掉，机制留下，名字换成「浊胎」。**

**新机制：增殖（spawn）**

| 字段 | 值 |
|---|---|
| 类型 | 祟 |
| 费用 | 0 |
| 可打出 | 否 |
| 效果 | 回合开始时，若手牌中有「浊胎」，则在手牌中再生成 1 张（手牌上限 10 张内） |
| 移除 | 任意「弃牌」效果可一次性清除全部「浊胎」 |

**为什么这条值得做**：现有「邪祟」是静态占位，威胁固定，玩家可以无视。增殖型诅咒会持续恶化，逼玩家为「弃牌」留卡位，**直接改变构筑偏好**——这是真正的机制增量。

**风险**：可能过度惩罚 slow 卡组。上限设为「手牌 10 张」自然封顶；另设单场战斗最多增殖 5 张。

**验收**：增殖不触发抽牌堆；手牌满时不再增殖；弃 1 张牌时清除全部而非一张；牌组查看界面显示「浊胎 ×N」。

**成本**：2 人日。

## 6. 多语言落地

游戏已支持 11 语种（zh_CN / en / ja / ko / es / pt_BR / ru / de / fr / it / id），梗的翻译必须分级处理，否则会出现「中文好笑、外语莫名其妙」的情况。

| 类型 | 处理 | 案例 |
|---|---|---|
| **A 类·可直译** | 11 语种全部翻译 | 已读乱回（left on read / 既読スルー / 읽씹）、电子布洛芬（digital ibuprofen / デジタル鎮痛剤） |
| **B 类·需改写** | 保留结构，替换为本地等效的荒诞反转 | 雪山问话的第三选项，英语可写 "I'm the duck." 但更自然的是 "I'm the soy duck they were asking about." 需按语种重写而非逐字翻 |
| **C 类·不可译** | 放弃该梗，走替代文案 | 「浊胎」本身就是 C 类的处理结果——把梗抽象成意象，反而全球通用 |

**工程建议**：

1. 所有梗文案进 i18n 词表，与 `ui.*` 分开，方便整段替换；本期实际用的是 `ev.*`（事件）、`diag.*`（确诊）、`c.*` / `r.*`（卡与旧物）分段——**没有新建 `meme.*`**，因为梗已经化进各系统的命名空间，单独一段反而会让「这句台词属于哪个界面」变模糊；
2. **不要硬编码**。梗的保鲜期短，留出「整段换文案」的能力，下个版本可以低成本换一批；
3. 词条改动后必须跑一次覆盖率自检：11 个语种 × 422 条，缺一条就会回退英文，界面会突然冒出英文单词。

### 6.3 更新频率（已拍定：一周一次）

梗文案按**每周一次**更新，跟版本解耦。

这个频率是从两个约束倒推的：

| 约束 | 结论 |
|---|---|
| 梗的自然半衰期 | 热梗从爆发到无人提及约 3–8 周。一个月一更，永远在追尸体；一周一更，能踩在热度还在的时候 |
| 翻译成本 | 一次更新按 8–15 条计，11 语种约 90–165 条译文。这是**一个人一天能做完**的上限，超过就必然要机翻，调性会崩 |

**落地方式**：词条改动只碰 11 个 `scripts/i18n/*.gd`，不动逻辑，因此可以走「改词 → 跑覆盖率自检 → 出包」的固定流水线，不占版本窗口。频率是一周一次，但**不承诺每周都有新梗**——没有值得做的梗就不更，硬凑比不更伤。

> 这条推翻了初版文档里「保鲜期 6–18 个月」的假设。那个数字是给「行为类梗」的（已读乱回这类确实能活很久），但**事件文本里的具体梗**活得远没有那么长，两者必须分开看：机制可以留五年，文案不行。

## 8. 风险与合规

| 风险 | 等级 | 应对 |
|---|---|---|
| **调性被破坏** | 高 | 三条硬规则里的「角色不玩梗」；上线前找 3 个没玩过的人盲测，问「这游戏是不是在搞笑」 |
| **IP 侵权** | 高 | 已淘汰全部带 IP 的梗；画面不得出现任何可识别的第三方形象 |
| **梗速朽** | 中 | 只选行为/情绪类；文案集中在 `meme.*` 段，可整段替换 |
| **多语言翻译衰减** | 中 | A/B/C 三级处理；B 类必须找母语者重写而非机翻 |
| **数值失衡** | 中 | 委屈、增殖两条需要各做 20 局模拟；增殖设 5 张硬上限 |
| **审核风险** | 低 | 无政治、无低俗、无迷信宣扬（游戏本身已是志怪题材，注意不作现实占卜/治病引导，「确诊」文案避免使用真实病名） |
| **玩家反感玩梗** | 中 | 确诊标签只出现在结算页，不打断任何操作；暂不做开关（本期标签总量小，且它不影响玩法）。若差评里出现「被冒犯」，再补设置项 |

> 「确诊」这个词在中文语境里是梗，但在部分市场可能被理解为医疗声明。**所有语种的文案统一使用「比喻性标签」，不出现真实疾病名**，商店描述里也避免出现 medical 相关词汇。

## 10. 决策记录（v1.1 全部拍定）

上一版这里列的是 6 个问号，现在全部有结论。**结论即约束**，后续版本不得在没有新证据的情况下推翻。

| # | 事项 | 结论 | 理由 | 落地方式 |
|---|---|---|---|---|
| 1 | 确诊标签要不要给 Buff | **不给** | 给了就变成就系统，玩家会为标签扭曲打法，「被看见」变成「被考核」 | 硬约束，写进 P0-1；分享卡只展示不改数值 |
| 2 | 「酱板鸭」这类祟牌是否进图鉴 | **进** | 祟是真实存在的一类牌，藏起来收集度就是假的；祟文案本身是氛围资产 | 图鉴页显示 52 张，含全部 7 张祟 |
| 3 | 事件节点等地图还是先做概率插入 | **等地图，且已完成** | 地图已上线，事件是可见可绕开的节点，比概率插入更可控 | 降级方案作废，不再保留 |
| 4 | 委屈机制是否只对玩家生效 | **只对玩家** | 双方都挨打变强，等于抹平劣势方的翻盘窗口，机制失效；且敌人多，层数显示难读 | `Battle.gd` 的 `grievance` 仅玩家字段 |
| 5 | 梗文案的更新频率 | **一周一次** | 热梗半衰期 3–8 周；一周的量（8–15 条 × 11 语种）是一个人一天的上限 | 只改词表走固定流水线，与版本解耦；无好梗可不更 |
| 6 | 确诊标签能否在商店截图露出 | **可以** | 它是最容易被转发的产物，露出来等于把分享入口前置到商店页 | 商店截图可用确诊面板，但**文案不得出现真实病名**，见第 8 节合规说明 |

### 10.1 由决策派生的两条新约束

1. **文案更新不得改逻辑**。既然定了一周一更，就必须保证「换词不换行为」——所有梗文案只能落在 `scripts/i18n/*.gd`，一旦需要改 `.gd` 逻辑才能更，说明这条梗当初的转译做错了，应当回退重做。
2. **商店素材与游戏内必须同一套标签**。第 6 条决策允许确诊标签出现在商店截图，意味着商店页的标签名就是玩家进游戏后看到的那个名字，不能为了商店另起一套更好听的叫法——两套名字会让玩家觉得被骗。
