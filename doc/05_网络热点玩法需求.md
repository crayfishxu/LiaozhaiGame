| 项 | 结论 |

## 1. 背景与目标

### 1.1 现状

v0.1.6 已有：三关、17 张双面卡、4 个敌人、11 语种、完整的结算与暂停流程。玩起来是通的，但**缺三样东西**：

1. **缺意外**——三关是线性推进，敌人行动完全可预测，第二遍就没有新鲜感；
2. **缺表达**——玩家没有做「只有我会这么选」的机会，全程在算最优解；
3. **缺谈资**——打完没有任何可分享的产物，社区里传不开。

这三样恰好是梗能补的，但只补第三样，游戏并不会更好玩。所以本文档的原则是：**梗是引子，改的是机制。**

### 1.2 一句话立场

> **能被玩家说出口的梗，做成机制；只能被玩家看出来的梗，写进文案；两者都不沾的，不做。**

举例说明三种处理：

| 梗 | 处理 | 理由 |
|---|---|---|
| 已读乱回 | **做成卡**，显相「已读」/ 本相「乱回」 | 它本身是一个「行为」，能直接翻译成规则，且和双面卡机制天然咬合 |
| 正式确诊为 XX | **做成结算标签**，读你的打法数据 | 它是一种「被评价」的欲望，做成系统比写成玩笑有用 |
| 野生狗奶 | **只写进旧物 flavor text** | 它的乐趣就在那句无厘头，做成机制反而不好笑 |

### 1.3 成功指标（上线后 30 天）

| 指标 | 现状 | 目标 | 说明 |
|---|---|---|---|
| 结算页分享率 | 0% | ≥ 8% | 「确诊」标签 + 分享按钮 |
| 次日留存 | 待埋点 | +5pp | 事件节点带来「下一局可能不一样」的预期 |
| 单局重开率 | 待埋点 | +10pp | 见 P1-1 委屈机制，降低挫败感 |
| 事件节点第三选项点击率 | — | 25%–40% | 这是「梗被接住」的直接证据，低于 15% 说明梗选错了 |

## 2. 梗的选用原则

这一节比后面的需求更重要。选错梗的代价不是「不好笑」，是让游戏显得廉价。

### 2.1 三条硬规则

**规则一：只用「行为 / 情绪类」，不用「事件 / IP 类」。**

行为类梗（已读乱回、正式确诊、电子布洛芬）描述的是人的普遍状态，五年后依然成立；事件类梗（雪山救狐狸的台词、牢九门）依附于某个具体作品或某次传播，半年后就是化石。

**规则二：零 IP 风险。**

| 淘汰 | 原因 |
|---|---|
| 袋鼠 MJ / 外卖骑手梗 | 形象版权属美团，商用即侵权 |
| 牢九门 | 源自《王者荣耀》，腾讯 IP |
| 光之国大乱斗 | 奥特曼 IP |
| 大智斗时代 / 五代石国 | 《熊出没》IP |
| 奶娃（原形象） | 来源作者已删号，权属不清 |

**规则三：叙述者可以玩梗，角色不可以。**

游戏里有三种声音：旁白、角色、系统提示。**只有旁白和系统提示能玩梗**，聂小倩和姥姥的台词必须保持原样。玩家能接受一个说风凉话的旁白，不能接受一个说网络用语的清代女鬼。

### 2.2 本期入选与落选

| 梗 | 入选 | 形态 | 备注 |
|---|---|---|---|
| 正式确诊为 XX | ✅ P0 | 结算标签 | 自嘲，零风险，跨语言可译 |
| 雪山救狐狸 | ✅ P0 | 事件节点 | 只借「荒诞反转」的结构，不照搬台词 |
| 已读乱回 | ✅ P0 | 卡牌 | 与双面卡机制咬合最紧的一条 |
| 哭哭马 | ✅ P1 | 状态 + 表情 | 只取「委屈」情绪，不用马的 IP 形象 |
| 电子布洛芬 | ✅ P1 | 休息节点变体 | 概念可直译 |
| 夯爆了 | ✅ P2 | 伤害播报 | 纯表现层，成本最低 |
| 我要验牌 | ✅ P2 | 情报按钮 | 梗已存在三十年，属于「复古长青」 |
| 野生狗奶 | ✅ P2 | 旧物 flavor | 只作文案，不做机制 |
| 纳垢式增殖 | ✅ P1 | 祟牌新机制 | 见 P1-3，梗已「化」进世界观 |

## 4. 需求清单

> 优先级：P0 本期必做 ｜ P1 本期争取 ｜ P2 下期

### P0-1 确诊（正式确诊为 XX）

**梗来源**：2026 年最出圈的自嘲梗，用医院诊断书的句式调侃自己的生活状态。

**玩法转译**：局末按玩家的真实打法数据，给一个「病名」+ 一句短评。不是随机抽，是读数据算出来的——玩家能感觉到「它真的在看我」。

**判定数据**（本局累计，不跨局）

| 变量 | 含义 |
|---|---|
| `R` | 本局回合数 |
| `P` | 打出卡牌总数 |
| `S` | 空过回合数（结束回合时手牌 ≥ 3） |
| `L` | 自损魂火总量 |
| `B` | 获得障总量 |
| `D` | 弃牌总数 |

**八个档案**（打分取最高，同分按表中顺序）

| 病名 | 条件 | 短评 |
|---|---|---|
| 确诊为「摆烂人」 | `S ≥ R × 0.3` | 你什么都没做，雾自己散了。 |
| 确诊为「猛冲怪」 | `P / R ≥ 3.5` 且 `L ≥ 10` | 你不是在打牌，你在拿命换牌。 |
| 确诊为「龟壳精」 | `B ≥ 100` | 你把自己包好了，连风都进不来。 |
| 确诊为「手滑居士」 | `D ≥ 15` | 有些牌，是它自己想走的。 |
| 确诊为「内耗选手」 | `R ≥ 25` | 你在里面待了很久。她也陪你待了很久。 |
| 确诊为「嘴硬」 | 通关时魂火 ≤ 10 | 只剩一口气，还说不疼。 |
| 确诊为「查无此人」 | `R ≤ 2` 且失败 | 兰若寺没记住你的名字。 |
| 确诊为「情绪稳定」 | 全程单次受伤 ≤ 8 且通关 | 你从头到尾没有慌过。 |

**输出**：结算面板底部一行小字 `—— 本局确诊为「猛冲怪」`，下方一个「复制病历」按钮，文本格式：

```
【聊斋美人】本局确诊为「猛冲怪」
23 回合 / 出牌 86 张 / 自损 14 / 怨气峰值 9
你路过兰若寺，顺手拆了半座庙。
```

**设计约束**：**不给任何属性加成**。一旦有加成，玩家会为了标签扭曲打法，它就变成了第二个成就系统，不再是「被看见」。

**验收**：八个档案在正常对局中均可触达；不出现两份档案分数完全相同（同分走表内顺序）；失败局也要出标签。

**成本**：1.5 人日（纯结算层，无战斗改动）。

### P0-2 雪山问话（雪山救狐狸）

**梗来源**：AI 短片《雪山救狐狸》的荒诞对话结构——「你可曾在雪山救过一只狐狸？」「我不是狐狸，我是那只酱板鸭。」

**玩法转译**：做成一个**问话事件**。关键不在台词，在**第三个选项**。前两个选项是正常的游戏选择，第三个是「不按剧本来」——玩家一旦发现这里可以乱答，就会去试。

**触发**：进入问话节点（降级方案：每层清场后 30% 概率插入）

**界面**：雾中一个背对你的人影，头顶一行字：

> 「你可曾在雪山救过一只狐狸？」

**三个选项**

| 选项 | 结果 | 设计意图 |
|---|---|---|
| ① 救过 | 获得「狐裘残片」：魂火上限 +5 | 正常玩家的安全答案 |
| ② 没有 | 战一场（游魂 ×1，血量 ×1.3） | 给想打架的人 |
| ③ 我是那只酱板鸭 | 获得祟牌「酱板鸭」 | **奖励乱答的人** |

**「酱板鸭」**（祟 · 0 费 · 不可打出 · 不可移除）

> 占一个手牌位。每回合开始时回复 1 点魂火。
> flavor：*它本来是只鸭子。后来它被问烦了。*

这是全游戏唯一一张「负面牌但有正面收益」的祟——用 1 个手牌位换每回合 1 点回复。玩家会边骂边留着它。

**验收**：三个选项都能选到；选③后手牌里确实多一张「酱板鸭」；「酱板鸭」不可打出、不可被弃牌效果以外的方式移除；每回合开始确实 +1 魂火。

**降级**：无旧物系统时，选项① 改为「魂火上限 +5」直接生效。

**成本**：3 人日（含节点 UI、判定、新祟牌）。

### P0-3 已读 / 乱回

**梗来源**：社交行为梗——看到消息、不认真回、答非所问，既礼貌又终结话题。

**玩法转译**：这是全场最巧的一条——**双面卡机制本身就是「已读」和「乱回」**。显相是「我看到了」，翻面是「我乱答」，一张牌两个面，正好对上。

**新机制：意图篡改（rewrite）**
与既有的「缠绕」区分：

| | 缠绕 | 篡改 |
|---|---|---|
| 效果 | 目标完全跳过回合 | 把目标的意图**换成另一个**可预测的动作 |
| 心智 | 我让它停下 | 我替它决定做什么 |
| 收益 | 消除威胁 | 把「噬魂 16」变成「乱打 4」，同时保留信息 |

**卡牌**

| 字段 | 值 |
|---|---|
| 编号 | Q26（Q 系列已排到 Q25，取下一个空号；当前代码仅实现 17 张，编号待重新映射） |
| 类型 | 念 |
| 费用 | 1 |
| 目标 | 需要 |
| 显相「已读」 | 目标本回合意图改为「防御 6」 |
| 本相「乱回」 | 目标本回合意图改为「攻击 4，随机目标」，并抽 1 张牌 |

**为什么是这两个数值**：防御 6 相当于帮敌人做了一次最低效的选择；攻击 4 随机目标在双敌人关卡里可能打到自己人——玩家会为了看这一下而反复用。

**多语言**：这条是**全球通用**的罕见案例。日语的「既読スルー」、韩语的「읽씹」、英语的「left on read」都是完全对等的日常说法，直译即可，不需要改写。

**验收**：对已缠绕的敌人使用时，篡改覆盖缠绕状态（以最后生效者为准）；对死人无效；抽牌部分走正常抽牌堆逻辑。

**成本**：2 人日。

### P1-1 委屈（哭哭马）

**梗来源**：2026 马年的委屈脸小马玩偶，代表「轻度崩溃、日常 emo、但不矫情」。

**玩法转译**：不做表情包，做一条**负反馈补偿机制**。当前版本玩家一旦被压制就进入死亡螺旋，没有任何翻盘钩子——这才是真正影响乐趣的地方。

**新状态：委屈**（玩家侧）

| 项 | 规则 |
|---|---|
| 获得 | 单回合内累计受到 ≥ 10 点伤害时 +1 层 |
| 上限 | 3 层 |
| 效果 1 | 回合结束时，每层获得 3 点障 |
| 效果 2 | 受到伤害时，消耗 1 层，减免 3 点 |

**视觉**：玩家血条右侧出现一个小马剪影，三档表情随层数变化（低头 / 眼角泛红 / 掉一滴泪）。**不使用任何现有玩偶形象**，自绘抽象剪影。

**为什么这是「提高乐趣」而不是玩梗**：它把「挨打」从纯损失变成了资源积累，玩家在劣势时会想「再撑一回合，我马上有障了」，而不是「这局没了」。这是纯粹的数值心理学，和梗无关——梗只负责让这个状态有个名字。

**验收**：单回合受伤 10 点触发；三层封顶；减免在障之后结算；回合结束的障不参与「本回合」判定，不留到下一回合。

**成本**：2.5 人日（含数值调平）。

### P1-2 电子布洛芬

**梗来源**：能治愈坏情绪的网络事物——刷视频、看萌宠、听歌。

**玩法转译**：做成**休息节点的第三个选项**。正常休息节点是「回血 / 删牌」，第三个选项是「什么都不干，就歇会儿」——收益低但带一个下局战斗的小 Buff。

| 选项 | 效果 |
|---|---|
| ① 打坐 | 回复 15 魂火 |
| ② 焚稿 | 移除 1 张牌 |
| ③ 檐下听雨 | 回复 8 魂火 + 下一场战斗首次出牌不消耗心力 |

**设计意图**：给「我这套牌已经成型了，不需要再改」的玩家一个不亏太多的选项。目前这类玩家在休息节点只能硬选一个不需要的收益。

**flavor**：*雨下了很久。你没有想任何事，这在兰若寺是奢侈的。*

**降级**：无地图系统时，改为「战后 20% 概率出现」。

**成本**：1.5 人日。

### P1-3 浊胎（增殖祟）

**梗来源**：AI 生成的一团黄色不明生物，创作者自己都删号跑了，留下「亿万二创，找不到原作者」的荒诞局面。

**玩法转译**：**这是「化梗」而不是「贴梗」的示范**。直接叫「奶娃」会破坏世界观，也会显得在蹭；但它描述的东西——一个来路不明、自我复制、越堆越多的怪东西——恰好就是「祟」的定义。

所以：**梗丢掉，机制留下，名字换成「浊胎」。**

**新机制：增殖（spawn）**

| 字段 | 值 |
|---|---|
| 类型 | 祟 |
| 费用 | 0 |
| 可打出 | 否 |
| 效果 | 回合开始时，若手牌中有「浊胎」，则在手牌中再生成 1 张（手牌上限 10 张内） |
| 移除 | 任意「弃牌」效果可一次性清除全部「浊胎」 |

**为什么这条值得做**：现有「邪祟」是静态占位，威胁固定，玩家可以无视。增殖型诅咒会持续恶化，逼玩家为「弃牌」留卡位，**直接改变构筑偏好**——这是真正的机制增量。

**风险**：可能过度惩罚 slow 卡组。上限设为「手牌 10 张」自然封顶；另设单场战斗最多增殖 5 张。

**验收**：增殖不触发抽牌堆；手牌满时不再增殖；弃 1 张牌时清除全部而非一张；牌组查看界面显示「浊胎 ×N」。

**成本**：2 人日。

### P2-1 验牌（我要验牌）

**玩法转译**：中栏加一个「验牌」按钮，显示当前所有敌人的**未来 3 步行动序列**（现在只显示下一步）。每场战斗限 1 次。

**设计意图**：情报本身就是乐趣。给玩家一次「提前看穿」的机会，用来做「要不要现在梭哈」的决策。

**flavor**：*「拿出来我看看。」*

**成本**：0.5 人日。

## 5. EARS 需求条目

> 类型：`[U]` 通用 ｜ `[E]` 事件驱动 ｜ `[S]` 状态驱动 ｜ `[W]` 异常 ｜ `[O]` 可选

### 5.1 确诊（DIA）

| 编号 | 类型 | 需求描述 |
|---|---|---|
| REQ-DIA-001 | [E] | 当一局结束（通关或失败）时，系统应统计 R/P/S/L/B/D 六项数据并生成确诊标签。 |
| REQ-DIA-002 | [U] | 系统应始终按八个档案的条件打分，取分数最高者；同分时按文档表内顺序取靠前者。 |
| REQ-DIA-003 | [W] | 若所有档案得分均为 0，则系统应默认输出「确诊为「查无此人」」并附中性短评。 |
| REQ-DIA-004 | [U] | 确诊标签应始终只做展示，不得修改任何战斗数值或局内状态。 |
| REQ-DIA-005 | [O] | 系统应提供「复制病历」按钮，将标签与统计写入系统剪贴板。 |

### 5.2 意图篡改（RWT）

| 编号 | 类型 | 需求描述 |
|---|---|---|
| REQ-RWT-001 | [E] | 当「已读」生效时，系统应将目标本回合意图替换为 `{kind:"defend", val:6}`。 |
| REQ-RWT-002 | [E] | 当「乱回」生效时，系统应将目标本回合意图替换为 `{kind:"attack", val:4, random_target:true}` 并抽 1 张牌。 |
| REQ-RWT-003 | [S] | 当目标同时处于缠绕与篡改状态时，系统应以最后写入的意图为准。 |
| REQ-RWT-004 | [W] | 若目标已死亡，则系统应忽略篡改效果且不消耗心力。 |

### 5.3 事件问话（EVT）

| 编号 | 类型 | 需求描述 |
|---|---|---|
| REQ-EVT-001 | [E] | 当进入问话事件时，系统应展示问句与三个选项，且三个选项均可点击。 |
| REQ-EVT-002 | [E] | 当玩家选择「我是那只酱板鸭」时，系统应将「酱板鸭」加入牌组而非手牌。 |
| REQ-EVT-003 | [U] | 「酱板鸭」应始终不可打出、不参与弃牌堆循环，且每回合开始时回复 1 点魂火。 |
| REQ-EVT-004 | [W] | 若手牌已满，则「酱板鸭」的回合开始回复效果失效但不报错。 |

### 5.4 委屈（GRV）

| 编号 | 类型 | 需求描述 |
|---|---|---|
| REQ-GRV-001 | [S] | 当玩家单回合累计受伤 ≥ 10 点时，系统应给予 1 层委屈，上限 3 层。 |
| REQ-GRV-002 | [E] | 当玩家受到伤害时，系统应优先消耗 1 层委屈减免 3 点，再结算障。 |
| REQ-GRV-003 | [E] | 当玩家回合结束时，系统应按委屈层数 ×3 给予障。 |
| REQ-GRV-004 | [U] | 委屈状态应始终在玩家血条侧显示对应档位的剪影。 |

### 5.5 增殖祟（SPN）

| 编号 | 类型 | 需求描述 |
|---|---|---|
| REQ-SPN-001 | [E] | 当玩家回合开始时，若手牌中有「浊胎」且手牌未满，系统应再生成 1 张。 |
| REQ-SPN-002 | [W] | 若单场战斗已增殖 5 张，则系统应停止增殖。 |
| REQ-SPN-003 | [E] | 当玩家触发任意弃牌效果时，系统应一次性移除手牌中全部「浊胎」。 |

## 6. 多语言落地

游戏已支持 11 语种（zh_CN / en / ja / ko / es / pt_BR / ru / de / fr / it / id），梗的翻译必须分级处理，否则会出现「中文好笑、外语莫名其妙」的情况。

| 类型 | 处理 | 案例 |
|---|---|---|
| **A 类·可直译** | 11 语种全部翻译 | 已读乱回（left on read / 既読スルー / 읽씹）、电子布洛芬（digital ibuprofen / デジタル鎮痛剤） |
| **B 类·需改写** | 保留结构，替换为本地等效的荒诞反转 | 雪山问话的第三选项，英语可写 "I'm the duck." 但更自然的是 "I'm the soy duck they were asking about." 需按语种重写而非逐字翻 |
| **C 类·不可译** | 放弃该梗，走替代文案 | 「浊胎」本身就是 C 类的处理结果——把梗抽象成意象，反而全球通用 |

**工程建议**：

1. 所有梗文案进 i18n 词表新增 `meme.*` 段，与 `ui.*` 分开，方便整段替换；
2. 梗的 flavor text 用独立的 `flavor.*` 前缀，允许某些语种留空回退英文；
3. **不要硬编码**。梗的保鲜期是 6–18 个月，留出「整段换文案」的能力，下个版本可以低成本换一批。

## 7. 埋点

| 事件 | 参数 | 用途 |
|---|---|---|
| `diagnosis_shown` | `label`, `R`, `P`, `L` | 八个档案的分布，检查是否有档案从不触发 |

| `verify_used` | `wave` | 验牌的使用时机 |

## 8. 风险与合规

| 风险 | 等级 | 应对 |
|---|---|---|
| **调性被破坏** | 高 | 三条硬规则里的「角色不玩梗」；上线前找 3 个没玩过的人盲测，问「这游戏是不是在搞笑」 |
| **IP 侵权** | 高 | 已淘汰全部带 IP 的梗；画面不得出现任何可识别的第三方形象 |
| **梗速朽** | 中 | 只选行为/情绪类；文案集中在 `meme.*` 段，可整段替换 |
| **多语言翻译衰减** | 中 | A/B/C 三级处理；B 类必须找母语者重写而非机翻 |
| **数值失衡** | 中 | 委屈、增殖两条需要各做 20 局模拟；增殖设 5 张硬上限 |
| **审核风险** | 低 | 无政治、无低俗、无迷信宣扬（游戏本身已是志怪题材，注意不作现实占卜/治病引导，「确诊」文案避免使用真实病名） |
| **玩家反感玩梗** | 中 | 确诊标签可关闭（设置项），默认开 |

> 「确诊」这个词在中文语境里是梗，但在部分市场可能被理解为医疗声明。**所有语种的文案统一使用「比喻性标签」，不出现真实疾病名**，商店描述里也避免出现 medical 相关词汇。
