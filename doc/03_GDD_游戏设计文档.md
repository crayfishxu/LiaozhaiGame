## 1. 术语与单位

**全项目术语以此表为准。文案、代码、文档、UI 一律使用左列名称。**

| 术语 | 含义 | 代码标识 | 禁止使用的同义词 |
|------|------|----------|------------------|
| **心力** | 每回合可用于出牌的资源 | `energy` | 能量、法力、费用池 |
| **魂火** | 玩家的生命值 | `hp` | 血量、生命、HP |
| **障** | 伤害吸收值，回合开始清零 | `block` | 护盾、护甲、格挡 |
| **怨气** | 受伤积累的战斗资源 | `grudge` | 怒气、愤怨 |
| **祟毒** | 回合结束掉血的负面层数 | `poison` | 中毒、毒素 |
| **祟弱** | 造成伤害降低 25% 的负面层数 | `weak` | 虚弱、减攻 |
| **缠绕** | 目标无法行动的回合数 | `bind` | 眩晕、定身、冻结 |
| **显相** | 卡牌的正面：世人眼中的她 | `xian` | 正面、表相 |
| **本相** | 卡牌的另一面：真实的她 | `ben` | 反面、真相 |
| **情念** | 卡牌（玩家收集与打出的单位） | `card` | 卡、牌、技能卡 |
| **旧物** | 遗物，本局永久生效的被动道具 | `relic` | 遗物、法宝、饰品 |
| **悟道点** | 局外货币，用于解锁内容 | `insight` | 金币、经验、代币 |
| **心劫** | 一局完整的游戏流程 | `run` | 局、把、轮次 |
| **引魂人** | 玩家扮演的角色 | `player` | 主角、玩家角色 |
| **妖灵** | 可操作的女性角色（聂小倩等） | `spirit` | 角色、英雄、卡池角色 |
| **节点** | 地图上的一个事件点 | `node` | 格子、房间 |
| **层** | 大地图的一个章节 | `act` / `layer` | 章节、关 |
| **金** | 局内货币，用于商店 | `gold` | 金币、钱 |

### 1.1 数值单位约定

| 单位 | 说明 |
|------|------|
| 1 点伤害 | 扣除 1 点魂火（先扣障） |
| 1 点障 | 吸收 1 点伤害，回合开始清零 |
| 1 层祟毒 | 回合结束时扣 1 点魂火，然后层数 -1 |
| 1 层祟弱 | 造成伤害 ×0.75，回合结束层数 -1 |
| 1 回合缠绕 | 目标跳过 1 次行动 |
| 1 点心力 | 约等于 6 点伤害或 6 点障（基准，见第 7 章） |

## 2. 核心玩法框架

### 2.1 一句话

玩家扮演引魂人，与妖灵结契，用她的情念构筑牌组，穿过三层心劫，解开她的执念。

### 2.2 三层循环

```
【局外 · 持久】
  选择妖灵 → 配置初始牌组 → 携带至多 8 个旧物 → 进入心劫
        ↓
【局内 · 8–15 分钟】
  第 1 层「凡尘」 → 第 2 层「幽冥」 → 第 3 层「妖界」
  每层：分支地图（6 行）→ 6–8 个节点 → 层 Boss
  节点产出：情念 / 旧物 / 金 / 悟道点
        ↓
【结算】
  通关或失败 → 获得悟道点 → 解锁新情念进池 / 解锁新妖灵
```

### 2.3 心流节奏

| 阶段 | 节点数 | 玩家状态 | 设计意图 |
|------|--------|----------|----------|
| 第 1 层前 3 行 | 3 | 牌组 12 张，流派未定 | 建立基础循环，做第一次流派倾向选择 |
| 第 1 层后 3 行 + Boss | 3–4 | 牌组 15–18 张 | 流派初现，验证构筑方向 |
| 第 2 层 | 6 | 牌组 20–24 张 | 流派成型，开始做取舍（删牌） |
| 第 3 层 | 5 + Boss | 牌组 25–30 张 | 检验构筑极限，Boss 是流派考试 |

## 3. 战斗系统

### 3.1 基础参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 初始魂火 | 50 | 全局共享，跨层不重置 |
| 每回合心力 | 3 | 可通过旧物提升至 4 |
| 每回合抽牌 | 5 | 可通过旧物提升 |
| 手牌上限 | 10 | 超出则不再抽牌 |
| 牌组上限 | 40 | 超出时不可再添加 |
| 初始牌组 | 12 张 | 见 4.4 |

### 3.2 回合流程

```
【玩家回合开始】
  1. 障清零
  2. 反伤清零
  3. 心力回复至上限
  4. 结算自身祟毒（掉血，层数-1）
  5. 触发「回合开始」类旧物与能力
  6. 抽 5 张牌
  7. 刷新敌人意图
        ↓
【玩家出牌阶段】
  任意顺序出牌，直到心力不足或主动结束
  每张牌打出后立即翻面并进入弃牌堆
        ↓
【玩家回合结束】
  1. 触发「回合结束」类效果
  2. 弃掉全部手牌（保留类除外）
        ↓
【敌方回合】
  按从左到右顺序，每个敌人依次执行意图
  执行后结算该敌人的祟毒、祟弱、缠绕
        ↓
【判定】任一方魂火归零 / 敌人全灭 → 进入结算
```

### 3.3 伤害结算

```
最终伤害 = (基础伤害 + 加值) × 易伤系数 × 祟弱系数 − 目标障值
```

| 修正项 | 数值 |
|--------|------|
| 祟弱系数 | 0.75 |
| 目标有障 | 先扣障，溢出部分扣魂火 |
| 反伤 | 攻击方结算后反受，无视障 |

**计算顺序（必须严格遵守）：**

1. 取基础伤害
2. 加上固定加值（如"攻击牌伤害 +1"）
3. 乘易伤（如有）
4. 乘祟弱系数并向下取整
5. 减目标障值
6. 剩余扣魂火

### 3.4 怨气规则

| 项 | 规则 |
|----|------|
| 获取 | 玩家每受到 1 次伤害（扣魂火 > 0）获得 2 点怨气 |
| 强化 | 持有旧物「半支金钗」时额外 +1；持有能力「怨气缠身·本相」时额外 +2 |
| 上限 | 无上限 |
| 消耗 | 仅「怨念·本相」消耗 |
| 跨战斗 | 保留至本层结束 |

### 3.5 敌人意图

- 每个敌人在玩家回合开始时展示下回合行动
- 意图类型：攻击 / 防御 / 施毒 / 强化 / 缠绕（被缠时显示"缠缚"）
- 玩家可通过「低眉」「缚魂」改变意图结果（降低攻击力或取消行动）

## 4. 卡牌系统

### 4.1 卡牌结构

每张情念包含两面，数据字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| 编号 | 字符串 | C=通用，Q=聂小倩专属，S=祟 |
| 卡名 | 字符串 | 2–4 字 |
| 类型 | 枚举 | 嗔（攻击）/ 障（防御）/ 念（技能）/ 执（能力）/ 祟（诅咒） |
| 费用 | 整数 | 消耗心力，0–3 |
| 目标 | 枚举 | 单体 / 全体 / 自身 / 无 |
| 稀有度 | 枚举 | 普通 / 稀有 / 史诗 / 传说 |
| 关键词 | 字符串 | 可空，见第 6 章 |
| 显相效果 | 文本 + 参数 | 正面 |
| 本相效果 | 文本 + 参数 | 反面 |

### 4.2 稀有度与掉率

| 稀有度 | 卡池实际占比 | 战斗奖励出现率 | 商店出现率 |
|--------|--------------|----------------|------------|
| 普通 | 25 张 / 49% | 60% | 50% |
| 稀有 | 18 张 / 35% | 28% | 32% |
| 史诗 | 6 张 / 12% | 10% | 14% |
| 传说 | 2 张 / 4% | 2% | 4% |
| **合计** | **51 张 / 100%** | 100% | 100% |

> 「卡池实际占比」是当前 51 张卡的真实分布（见附录 A.3）；「出现率」是奖励与商店抽取时的权重，两者独立。上线扩展至 142 张时，需重新平衡这两组数值。

### 4.3 卡池构成

| 类别 | 数量 | 说明 |
|------|------|------|
| 通用情念 | 20 | 所有妖灵可用 |
| 聂小倩专属 | 25 | 仅聂小倩可用，分幽怨流 / 情丝流 |
| 祟 | 6 | 诅咒牌，不可打出 |
| **合计** | **51** | MVP 版本 |

## 6. 关键词与状态

### 6.1 卡牌关键词

| 关键词 | 规则 |
|--------|------|
| **消耗** | 打出后从本局移除，不进入弃牌堆 |
| **保留** | 回合结束时不弃置，留在手牌 |
| **固有** | 战斗开始时必定在起始手牌中 |

### 6.2 状态效果

| 状态 | 作用对象 | 结算时机 | 持续 |
|------|----------|----------|------|
| 障 | 双方 | 受到伤害时抵扣 | 玩家回合开始时清零 |
| 祟毒 | 双方 | 各自回合结束掉血 | 每回合 −1 层 |
| 祟弱 | 双方 | 造成伤害时 ×0.75 | 每回合 −1 层 |
| 缠绕 | 仅敌人 | 跳过行动 | 每回合 −1 层 |
| 反伤 | 玩家 | 被攻击后反弹 | 本回合 |
| 怨气 | 玩家 | 受伤时累积 | 本层内保留 |

### 6.3 状态叠加规则

- 祟毒、祟弱、缠绕：**层数累加**，不刷新持续时间
- 障：**数值累加**，不设上限
- 反伤：**数值累加**，回合结束清零

## 7. 数值公式与平衡规则

### 7.1 心力价值基准

> **1 点心力 ≈ 6 点伤害 ≈ 6 点障 ≈ 1.2 张抽牌**

所有卡牌数值必须满足下表的"价值区间"，超出即视为不平衡。

| 费用 | 伤害区间 | 障区间 | 抽牌 | 备注 |
|------|----------|--------|------|------|
| 0 | 3–4 | 3–4 | 0 | 只做低价值填充 |
| 1 | 6–9 | 6–9 | 1–2 | 主力区间 |
| 2 | 12–18 | 12–18 | 2–3 | 需要额外效果时下调伤害 |
| 3 | 18–27 | 18–27 | 3 | 仅传说或强力史诗 |

### 7.2 附赠效果的价值折算

| 效果 | 折算价值（点伤害） |
|------|-------------------|
| 施 1 层祟毒 | +1.5 |
| 施 1 层祟弱 | +2 |
| 缠绕 1 回合 | +4 |
| 抽 1 张牌 | +3 |
| 获得 1 点心力 | +5 |
| 自损 1 点魂火 | −1 |

**校验公式：**

```
卡牌价值 = 伤害/障值 + Σ附赠效果价值 − Σ自损价值
约束：卡牌价值 / 费用 ∈ [5.5, 7.5]（费用 0 时直接看绝对值）
```

**示例校验 · G01 素手：**

- 显相：6 伤害 ÷ 1 费 = 6.0 ✓
- 本相：9 伤害 − 自损 2 = 7 价值 ÷ 1 费 = 7.0 ✓（本相允许接近上限）

### 7.3 本相设计规则

> **本相 = 显相 × 1.4~1.6 的强度，代价是失去魂火。**

| 费用 | 本相自损区间 |
|------|--------------|
| 0 | 1–2 |
| 1 | 2–3 |
| 2 | 3–6 |
| 3 | 6–8 |

**三条硬性约束：**

1. **本相必须"值得用"**：增益幅度必须大于自损折算价值
2. **本相必须有风险**：魂火低于 30% 时使用本相可能导致死亡
3. **不能只打本相**：单张牌本相用完必然翻回显相，强制节奏交替

### 7.4 稀有度加成

| 稀有度 | 相对普通卡的强度系数 |
|--------|----------------------|
| 普通 | 1.00 |
| 稀有 | 1.10 |
| 史诗 | 1.25 |
| 传说 | 1.40 |

> 稀有卡的"超模"通过更强效果或更低费用体现，而非直接堆数值。

### 7.5 战斗难度曲线

| 层 | 普通战魂火消耗预期 | 精英战 | Boss 战 |
